# 下载主页长期保留合同

本规则由软件作者在 2026-10-07 明确要求；后续每次发布必须执行。

1. 产品介绍、核心能力、适用场景、下载安装、实际截图、常见问题、隐私及平台边界、分享与关联软件入口长期保留。更新软件不得用简短发行日志覆盖主页。
2. 产品介绍之后立即放「近期新增与改进」，按新到旧保留 5 个用户可见功能或改进，不是 5 个版本，也不是测试流水账。一次发布可有多项；少于 5 项新变化时保留前版较新的条目凑满 5 项。旧功能仍保留在完整能力介绍中。
3. 发布前复核 recent-features.json（源仓内位置见发布脚本），更新 reviewed_version 和 5 个条目；有多语言文件时同步翻译。纯修复可按用户收益记为改进，不编造新功能。尚未公开的草稿、未验证能力不可列为可下载版本已有能力。
4. 模板是长期内容真源，生成 README 时保留 evergreen 标记与内容。readme-protection.json 记录受保护段落的 SHA-256；仅在作者要求修订产品定位或既有事实发生变化时，明确复核后同步修改模板和清单。
5. 运行 node scripts/readme-contract.mjs，检查长期内容未丢失、近期功能位置与 5 项上限。GitHub Actions 对推送和拉取请求执行检查；失败不是完成。发布后回读 README、下载资产、截图与仓库描述和主题。
6. 稳定下载入口使用 releases/latest；实际平台链接只指向已上传安装包。保留准确的签名、公证、收费、联网与功能验收限制，不承诺永久免费、无水印或所有平台能力相同。

## 多语言、视觉与演示永久保留

- 保留全部语言页面及语言导航：README.md, README.zh-TW.md, README.en.md。新版本必须同步各语言的下载信息与五项近期功能，禁止用中文悄悄代替缺失译文。
- 品牌横幅、语言导航、下载按钮、核心介绍、使用场景、FAQ 和双平台演示属于长期内容；未经用户明确要求不得删除、压缩或移出保护区。
- 演示使用 demo-videos.json 的实际视频地址，不得替换成频道首页或搜索链接；保留拍摄版本与中文讲解说明，更新演示须核验内容和公开状态。
- 用户明确要求改版时同步真源模板与 readme-protection.json；普通软件发布只更新版本、真实下载资产与最近五项功能。
