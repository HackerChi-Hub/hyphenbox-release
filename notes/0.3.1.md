# HyphenBox 0.3.1 预发行版

这是 `0.3.0` 的界面与交互修复版，不改变私有目录的安全边界。

## 本次修复

- 变化日志不再显示私有目录服务地址；
- 修复首页“添加免费 API”按钮永久禁用的问题；
- 点击“添加免费 API”现在会进入密钥保险箱的新建表单；
- “一键连接”改为独立的本地连接中心，不再重复“今日免费池”；
- 连接中心分别展示本地服务、签名目录、自有密钥和已核验模型路由四项真实状态；
- 当前模型路由为 0 时明确显示“一键连接尚未开放”，不会伪装成已经可用；
- 统一补充可点击按钮的鼠标指针反馈。

## 真实验收

- 已实际点击“添加免费 API”，确认进入密钥表单；
- 已实际点击“一键连接”，确认展示独立页面；
- 已检查变化日志，“私有服务”行和内部域名均未出现在界面；
- 完整前端、Worker 和 Rust 测试通过；
- DMG 完整性、应用签名结构、版本和 arm64 架构验证通过。

## 当前边界

- 仅发布 macOS Apple Silicon 安装包；
- 当前仍为 ad-hoc 签名，尚未完成 Apple Developer ID 正式签名与苹果公证；
- Windows 和 Intel Mac 安装包尚未完成真实构建验收；
- 用户 API Key 只进入系统安全存储，不上传黑粉盒子服务。
