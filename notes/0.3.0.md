# HyphenBox 0.3.0 预发行版

这一版完成了黑粉盒子私有目录更新链路。软件源码、免费 API 目录、采集系统、签名私钥和原始证据继续保持私有；公开仓库只提供安装包、版本说明和校验值。

## 本次更新

- 接入 Cloudflare Worker、D1 与 KV 组成的私有目录服务；
- 每台安装匿名注册独立设备身份，使用短期访问令牌与内存内刷新令牌读取目录；
- 启动时检查目录，此后每 6 小时检查一次；Mac 关机不影响用户获取已发布目录；
- 目录继续执行 Ed25519 签名、版本链、文件大小和 SHA-256 哈希验证；
- 内置目录升级到 `2026.08.28.2`，包含 17 条提供商记录；
- 17 条记录均补充结构化核验日期、核验范围和证据类型；
- 修正界面版本显示并完成图标比例验收；
- 用户自行保存的 API Key 仍只进入 macOS 钥匙串或 Windows 系统凭据存储，不上传目录服务。

## 当前边界

- 当前只发布 macOS Apple Silicon（M1、M2、M3、M4、M5 系列）安装包；
- Windows 与 Intel Mac 安装包尚未完成真实机器构建验收；
- 当前仍为 ad-hoc 开发签名，尚未完成 Apple Developer ID 正式签名和苹果公证；
- 目录目前是提供商级资源目录；尚未通过真实生成请求核验的模型不会进入自动路由；
- 信息采集程序已经准备了树莓派常驻任务模板，但树莓派部署不包含在此安装包中。

## macOS 首次打开

当前应用不是 Apple Developer ID 公证发行版。首次打开时，如果系统提示无法验证开发者，请在“系统设置 → 隐私与安全性”中确认“仍要打开”，或在访达中按住 Control 点击应用后选择“打开”。不要关闭系统全局安全保护。

## 安全边界

黑粉盒子分享的是官方免费 API 机会和用户自行申请凭据的接入方式，不分享泄露、共享或来源不明的 API Key。用户 Key、提示词和回答默认只在本机处理。
