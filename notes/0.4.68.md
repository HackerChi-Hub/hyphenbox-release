# 黑粉盒子 HyphenBox 0.4.68

修复免费额度冷却、自检错误展示，以及生成接口返回成功但没有实际回答的问题。

## 本版更新

- 正确读取 OpenRouter 免费日额度的重置时间；额度耗尽后等待真实恢复时间，不再每隔一分钟重复尝试。
- 实际生成中的空回答、纯思考、无效 JSON 和响应体内的错误，在交付前触发换路；有明确原因可供排查。
- 流式响应按完整 SSE 事件检查，处理心跳、跨数据块错误、UTF-8 字符和多行事件。有效输出前最多等待 120 秒、缓存 2 MiB，输出开始后立即流式转发。
- 已输出的正文和工具调用不自动重放；保留当前工具轮的模型绑定和工具签名。拒绝说明与内容过滤结果原样交付。
- 一键连接自检区分模型列表可读与真实生成成功，提供易读错误摘要、冷却倒计时和折叠技术详情。

## 下载

本次先提供 Windows、Linux x64 安装包；macOS 由维护者从同一源码提交手动构建后补充。

| 平台 | 安装文件 |
|---|---|
| Windows 10/11 x64 | `HyphenBox_0.4.68_x64-setup.exe`，推荐 |
| Windows 10/11 x64 | `HyphenBox_0.4.68_x64_en-US.msi` |
| Linux x64 | `HyphenBox_0.4.68_amd64.AppImage` |
| Debian/Ubuntu x64 | `HyphenBox_0.4.68_amd64.deb` |
| Fedora 等 x64 | `HyphenBox-0.4.68-1.x86_64.rpm` |

提供各平台 SHA-256 校验文件和构建验收记录。Linux 密钥保险箱需要桌面 Secret Service，例如 GNOME Keyring 或兼容配置的 KWallet。

## 发布与验证

本次为手动下载安装包，不包含更新器签名。Windows 安装器未作商业代码签名。现有 0.4.67 Mac 下载及自动更新清单继续保留，Mac 包与离线签名补齐后再切换完整发行。

本地回归覆盖 178 项 Rust 测试、11 项前端测试和 5 项版本检查测试。Windows、Linux 安装件由各自原生构建机生成，并执行核心回归、随包目录验签及发行二进制实际启动验收。生成链路使用隔离模拟上游测试，不代表各云服务商当前额度可用；Mac 尚未进行本版真机验收。

源码和目录服务保持私有。提供商密钥保存在用户系统安全存储中，模型请求由用户电脑连接其配置的提供商。
