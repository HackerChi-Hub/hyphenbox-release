# HyphenBox 0.2.0 预发行版

这是黑粉盒子的首个可浏览免费 API 提供商目录版本，供早期测试和反馈使用。

## 当前支持

- macOS Apple Silicon（M1、M2、M3、M4、M5 系列）；
- 17 条经过签名的提供商级免费 API 记录；
- 搜索、地区、免费类型和可用状态筛选；
- 展示额度、申请条件、风险提示、最近核验日期和证据链接；
- 本地统一服务只监听 `127.0.0.1`；
- 用户凭据写入系统安全存储，应用数据库不保存明文 Key；
- 目录 Ed25519 验签、文件哈希校验和远程更新安全边界。

## macOS 首次打开

当前应用使用 ad-hoc 开发签名，文件完整性已经验证，但不是 Apple Developer ID 公证发行版。首次打开时，如果系统提示无法验证开发者，请在“系统设置 → 隐私与安全性”中确认“仍要打开”，或在访达中按住 Control 点击应用后选择“打开”。不要关闭系统全局安全保护。

## 安全边界

黑粉盒子分享的是官方免费 API 机会和用户自行申请凭据的接入方式，不分享泄露、共享或来源不明的 API Key。用户 Key、提示词和回答默认只在本机处理。
