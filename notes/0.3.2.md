# HyphenBox 0.3.2 预发行版

这是采用全新方案 1 图标、扩展免费 API 信息源并加入自动实测留档链路的更新版。

## 本次更新

- 将 HyphenBox 图标重绘为标准矢量，并重新生成 macOS、Windows 和移动端全部尺寸，修复旧图标比例扭曲问题；
- 固化 20 个免费 API 信息来源，其中 17 个为官方来源、3 个仅用于发现候选；
- 新增 7 个提供商自动核验目标；
- 新增来源采集、公开模型列表观察、最小真实请求、失败复测和不可变历史记录；
- 第三方项目和社区清单只负责发现候选，不会直接修改正式目录；
- 没有完成模型级证据链时，软件继续明确显示 0 个可路由模型；
- 树莓派可以独立执行每日雷达周期，Mac 不需要持续开机。

## 真实验收

- 完整版本一致性、安全扫描、目录验签、前端、Worker 和 Rust 测试通过；
- DMG 已实际挂载；
- DMG 内应用版本回读为 `0.3.2`；
- 主程序架构回读为 `arm64`；
- 应用代码封印验证通过；
- 已从 DMG 启动应用，本地 `/health` 返回 `running` 和版本 `0.3.2`；
- 本地服务只监听 `127.0.0.1`；
- 已从应用包提取并检查方案 1 正式图标，未发现拉伸和比例扭曲。

## 当前边界

- 仅发布 macOS Apple Silicon 安装包；
- 当前仍为 ad-hoc 签名，尚未完成 Apple Developer ID 正式签名与苹果公证；
- Windows 和 Intel Mac 安装包尚未完成真实构建验收；
- 用户 API Key 只进入系统安全存储，不上传黑粉盒子服务；
- 免费 API 目录、实测历史和软件源码继续保持私有。
